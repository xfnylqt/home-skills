# 路线图

## 项目结构说明

本项目是一个 **skill 集合仓库**，包含三个相互独立、可单独安装的 Agent Skill。三个 skill 共享 `data/` 数据层。

| Skill | 状态 | 定位 |
|---|---|---|
| `peak-shift` | 🚧 v0.1.0 开发中 | 家庭峰谷电价用电优化 |
| `device-reborn` | 📋 骨架已就位 | 旧设备再利用向导 |
| `elder-bridge` | 📋 骨架已就位 | 长辈手机远程协助 |

## 里程碑

### M1 · `peak-shift` 可用（当前阶段）

- [x] SKILL.md 与工作流程定义
- [x] 省钱计算脚本（纯标准库）
- [x] 电价数据格式规范 `_SCHEMA.md`
- [x] 示例数据文件
- [ ] 覆盖 5 个省份的真实电价数据
- [ ] 家电功率默认值参考表
- [ ] 调度指引参考文档
- [ ] 端到端验证：输入省市与电器，输出可执行方案

**验收标准**：用户给出「北京 + 电热水器 2000W 每周 7 次」，能输出含时段、金额、设置方式的完整方案。

### M2 · 数据扩容

- [ ] 覆盖 20+ 省份真实电价数据
- [ ] 建立数据校验 CI（字段完整性 + 来源必填）
- [ ] 数据贡献指南完善

### M3 · `device-reborn` 可用

- [ ] 机型能力库初版（覆盖常见旧机型）
- [ ] 用途模板库：监控 / 相框 / 副屏 / 车机 / 服务器
- [ ] 配置生成脚本
- [ ] 安全须知文档

### M4 · `elder-bridge` 可用

- [ ] 常见问题库（微信 / 支付宝 / 系统设置）
- [ ] 话术脚本生成格式定义
- [ ] 防骗提示库

### M5 · 交叉场景

- [ ] 旧机改造为长辈专用机（device-reborn × elder-bridge）
- [ ] 旧机改造为家庭能源看板（device-reborn × peak-shift）
- [ ] 子女远程指导父母设置峰谷定时（peak-shift × elder-bridge）

## 长期方向

- 季节性电价支持（部分省份峰谷时段按季节调整）
- 阶梯电价与分时电价叠加计算
- 更多数据类型的社区共建（机型库、问题库）

## 不做什么

保持边界清晰，避免项目失焦：

- ❌ 不做硬件，不售卖设备
- ❌ 不做远程控制的底层实现（复用现有成熟方案）
- ❌ 不做医疗健康建议
- ❌ 不做商业/工业用电定价
- ❌ 不收集用户数据（全部本地处理）
